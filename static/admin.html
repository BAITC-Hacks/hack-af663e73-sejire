Пароль

API для проверки отзывов

Подбор на главной этот адрес не вызывает, и порядок карточек не меняется. Сервис сам не открывает 2GIS и Instagram. Кнопка у карточки отправляет название, город и услуги только сюда. Если API не умеет искать в сети, он должен прямо сказать, что живых отзывов нет, и не выдумывать их. Пустой ключ при сохранении оставляет прежний.

Новый подрядчик

Даты занятости можно оставить пустыми: тогда подрядчик не отмечен занятым. «Максимум часов» сравнивается с длительностью на главной. Пустое поле никого не отсекает.
