# Умный подбор подрядчиков

Веб-сервис для кейса Firebird AI. По городу, дате, формату, категории и бюджету он возвращает не больше трёх карточек. У каждой указано, почему подрядчик подходит, и открытый счёт: число сделанных работ плюс близость бюджета к середине вилки (от 0 до 1). Рядом — сравнение трёх карточек и почему другие из каталога не вошли. Интерфейс и формулировки переключаются на русский, казахский и английский.

Каталог в `data/contractors.csv` — пример из девяти подрядчиков. Колонки: `name`, `city`, `categories`, `formats`, `budget_min`, `budget_max`, `available_from`, `available_to`, `done_count`. Несколько категорий и форматов пишутся через `|`.

## Запуск

```powershell
python app.py
```

Откройте http://127.0.0.1:8080

Пример уже стоит в форме: Астана, 2026-09-23, офлайн, конференция, 1 500 000 тг. В выдаче Astana Events, Сарыарка Холл и Expo Crew.

Город, формат, характер мероприятия, бюджет, число гостей, язык и нужные услуги выбираются из списков. Новые значения, которые администратор вносит в базу, появляются в этих списках.

## Администратор

Панель: http://127.0.0.1:8080/admin

Логин `admin`, пароль `Astana2026`. Там можно добавить одного подрядчика или загрузить CSV целиком. Несколько категорий, форматов, языков и услуг в ячейке пишутся через `|`. Колонка `id` необязательна: если она совпадает с уже существующей, запись обновляется.
